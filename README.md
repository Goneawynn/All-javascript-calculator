# JavaScript Mini Projects 🧩
This repository contains a collection of simple JavaScript mini projects
created to practice JavaScript fundamentals, DOM manipulation,
and front-end logic flow.

Each folder in this repo is a **separate project** with its own focus.

---

## 📂 Project List

### 1️⃣ Simple Calculator
📁 `simpleCalculator/`

Simple calculator for basic operations:
- Addition
- Subtraction
- Multiplication
- Division

**Features:**
- Input two numbers
- Select an operator
- Input validation
- Display the calculation result

**Tech Stack:**
- HTML
- CSS
- JavaScript (DOM & Event Handling)
