# JavaScript Mini Projects 🧩
This repository contains a collection of simple JavaScript mini projects (focused on calculator)
created to practice JavaScript fundamentals, DOM manipulation,
and front-end logic flow.

Each folder in this repo is a **separate project** with its own focus.

---

## 📂 Project List

### 1️⃣ Simple Calculator
📁 `simpleCalculator/`

Simple calculator for basic operations:
- Addition
- Subtraction
- Multiplication
- Division

**Features:**
- Input two numbers
- Select an operator
- Input validation
- Display the calculation result

**Tech Stack:**
- HTML
- CSS
- JavaScript (DOM & Event Handling)

---

### 2️⃣ Basic Calculator and Temperature Converter
📁 `calculator2in1/`

A basic calculator built using buttons (similar to a physical calculator),
designed with **CSS Grid** and controlled fully via JavaScript.

**Supported Operations:**
- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)

**Features:**
- Button-based input (no manual typing)
- Dynamic display update
- Clear (`C`) functionality
- Error handling for invalid expressions
- Responsive layout using CSS Grid
- Digital-style display font

**Implementation Highlights:**
- `querySelectorAll` & `forEach` for event handling
- Single event logic for all buttons
- DOM-based input handling (no inline `onclick`)
- Clean separation between HTML, CSS, and JavaScript

**Tech Stack:**
- HTML
- CSS (Grid Layout)
- JavaScript (DOM & Event Handling)
